## Local Development

```bash
git clone https://github.com/VAIBHAV-w1/vaibhav-s-wandkar-portfolio.git
cd vaibhav-s-wandkar-portfolio
npm install
npm run dev
```

### Typecheck, Build & Preview

```bash
npm run typecheck
npm run build
npm run preview
```
